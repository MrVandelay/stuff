#Find commit in VCC build (with example):
1. Find SW version (DHUM) in ticket: 26.02.2.13.0045
2. Go to ara artifacts: https://ara-artifactory.volvocars.biz/ui/repos/tree/General/ARTCSP-PyPi
3. Go to HW name and version: uxcm-merged/master/v/26.02.2.13.0045/moose_mp_uxc10_vcc_gas/userdebug
4. Download "manifest_for_build.xml"
5. Open xml file with chrome and search for "bshalp"
6. Check hash of bshalp and find the commit in HT gerrit: https://source.haleytek.net/c/haleytek/qnx/vendor/haleytek/driver/display/prebuilts/bshalp_common_s3_csd_dim/+/79486
7. Open the xml file and check the hash of the BSHALP and compare it which commit it links to in https://source.haleytek.net/plugins/gitiles/haleytek/qnx/vendor/haleytek/driver/display/BSHALP_COMMON_S3_CSD_DIM/+log/refs/heads/master
8. Now you know which commit was in that build
