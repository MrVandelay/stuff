I was considering how to communicate Between Derating and LibLogTemperature thread.
I liked the idea of using shm_open(posix) to create a shared memory object for the producer thread to write to and subscriber to read
(This solution is similar to create nodes to communicate between threads.) It would also use the MsgReceivePulse and MsgSendPulse to notify
the subscriber that new data is available. This would make the solution even more decoupled which is nice.
However for this case where all threads are in the same process I think it is overkill.

Instead I suggest we update the ADC thread to support multiple subscribers but keep the communication to function call and std::unique_lock. (similar to today)

class Tiads1015 {
public:
    void publish(int new_data) {
        {
            std::lock_guard<std::mutex> lock(mtx_);
            latest_data_ = new_data;
            sequence_number_++;
        }
        cv_.notify_all(); // Notify subscribers
    }

    void stop() {
        {
            std::lock_guard<std::mutex> lock(mtx_);
            finished_ = true;
        }
        cv_.notify_all(); // Notify subscribers to stop
    }

    std::optional<int> get_data(int& last_seen_seq) {
        std::unique_lock<std::mutex> lock(mtx_);

        cv_.wait(lock, [this, last_seen_seq]() {
            return sequence_number_ > last_seen_seq || finished_;
        });

        if (sequence_number_ > last_seen_seq) {
            last_seen_seq = sequence_number_;
            return latest_data_;
        }

        return std::nullopt; // Kanalen stängd
    }

private:
    int latest_data_ = 0;
    int sequence_number_ = 0;
    bool finished_ = false;
    std::mutex mtx_;
    std::condition_variable cv_;
};

According to the EEPROM datasheet we can us 0x0200 - 0x1FFF for logging.
This gives us 0x1E00 bytes of memory to use for logging. This is more than enough for our needs.

       Loop

                1. Read ADC value

                3. Calulate avarage temperature and save to ram
            Every 10  minutes:
                Write average temperature to eeprom
